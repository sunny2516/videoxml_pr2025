# PR 口播工具 使用说明

## 环境要求
- Python 3.9+
- PyQt6

## 安装依赖
```
pip install PyQt6
```

## 启动方式
Windows 双击 `启动工具.bat`，或命令行运行：
```
cd pr_tool
python main.py
```

## 使用流程

### 第一步：工程管理（Tab1）
1. 输入工程名（如"感康"），点击【新建】
2. 或点击【打开工程文件】加载已有 `.prtool.json` 工程

### 第二步：素材配置（Tab2）
1. **序列参数**：设置帧率（默认30），分辨率（默认1080×1920）
2. **镜头库配置**：
   - 选择镜头母文件夹（包含OTC、摆放、药品名等子文件夹）
   - 点击【扫描子文件夹】自动导入关键词
   - 勾选启用/禁用关键词，也可手动添加
3. **口播文件夹组**：
   - 点击【＋ 添加口播组】
   - 填写组名（如"文案A"）
   - 选择口播输入文件夹和XML输出文件夹

### 第三步：生成XML（Tab3）
- **批量生成**：处理所有启用的口播组
- **单文件生成**：快速测试，直接选一个mp4+srt生成

### 第四步：PR导入
- 在Premiere Pro中：文件 → 导入 → 选择生成的 .xml 文件
- 每个xml对应一个序列，V1轨是口播，V2轨是B-roll镜头

## 文件夹结构要求

### 口播文件夹（两种结构均支持）
```
口播/
  ├── 口播1/
  │     ├── 视频.mp4
  │     └── 字幕.srt
  └── 口播2/
        ├── 视频.mp4
        └── 字幕.srt
```
或扁平结构：
```
口播/
  ├── 口播1.mp4
  ├── 口播1.srt
  ├── 口播2.mp4
  └── 口播2.srt
```

### 镜头母文件夹
```
镜头库/
  ├── OTC/         ← 文件夹名 = 关键词
  ├── 一盒/
  ├── 两盒/
  ├── 摆放/
  ├── 药品名/
  └── 手捏药品/
```

## 注意事项
- 建议安装 ffprobe（ffmpeg包含）以精确获取视频时长；否则工具会用SRT末尾时间估算
- 镜头素材不足1秒会自动跳过
- 素材时长≥字幕时长75%时从头截取，否则从尾部对齐截取
- 工程文件保存为 `.prtool.json`，可跨设备迁移（需确保路径可访问）

## 工程文件
工程配置以JSON格式保存，包含：
- 帧率、分辨率设置
- 镜头母文件夹路径
- 全部关键词↔文件夹映射
- 全部口播组配置（输入/输出路径）
